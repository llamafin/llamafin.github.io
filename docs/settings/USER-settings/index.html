Settings & customisation

Audience: End users and technical evaluators Last Updated: 2026-04-04 Version: 2.0.0

Overview​

Llamafin provides extensive customisation options across 10 settings categories, allowing you to tailor every aspect of the application to your preferences, from appearance and audio playback to download behaviour and notifications.

Account Settings​

Your Profile​

What's Stored:

  • Jellyfin username
  • User ID
  • Account capabilities (password, auto-login)
  • Last login and activity dates
  • User configuration and policy

Management:

  • View-only (managed by Jellyfin server)
  • Cleared automatically on logout
  • Synced with server on login

Server Source Settings​

Managing Server Connections​

Add Server:

  1. Enter server name and address
  2. Test connection
  3. Save configuration
  4. Multiple servers can be stored

Server Configuration:

  • Name: Friendly name for the server
  • Address: Full URL (e.g., http://192.168.1.100:8096)
  • Active Status: Which server is currently connected
  • Last Accessed: Timestamp of last connection

Server Operations:

OperationWhat It Does
AddStore new server configuration
EditUpdate address or name
RemoveDelete server configuration
ActivateSwitch to this server
Deactivate AllClear active status

Automatic Management:

  • Last used server remembered
  • Auto-activates on successful login
  • Connection history tracked

Playback Settings​

Audio Output​

Device Selection:

  • Default system output
  • USB audio interfaces
  • Bluetooth devices
  • HDMI/DisplayPort audio

Settings Persist: Your choice is remembered across sessions

Loudness Leveling​

What It Does:

  • Normalises volume across tracks
  • Prevents loudness jumps between songs
  • Based on ReplayGain standard

Configuration:

  • Enable/disable
  • Target loudness: -14 LUFS (standard)
  • Works with sonic analysis data

Sweet Fades (Crossfade)​

Smooth Track Transitions:

  • Enable/disable crossfade
  • Duration: 1-10 seconds
  • Default: 5 seconds

Benefits:

  • Professional DJ-style transitions
  • Eliminates abrupt track changes
  • Creates continuous listening flow

Equalizer​

10-Band Graphic EQ:

  • 60 Hz to 16 kHz coverage
  • -12 dB to +12 dB per band
  • 16 built-in presets
  • Custom EQ creation

Built-in Presets:

PresetBest For

  • Unlimited custom presets

Tone Controls​

Bass Control:

  • Range: -12 dB to +12 dB
  • Affects lowest 3 frequency bands
  • Graduated application

Treble Control:

  • Range: -12 dB to +12 dB
  • Affects highest 4 frequency bands
  • Graduated application

Preamp​

Purpose: Adjust overall output level

Range: 0-6 dB

Use Cases:

  • Compensate for quiet recordings
  • Prevent clipping with heavy EQ
  • Match output to amplifier

Limiter​

What It Does:

  • Prevents distortion at high volumes
  • High-ratio compression (12:1)
  • Transparent operation

When to Enable:

  • High-volume listening
  • Heavy EQ usage
  • Dynamic music with loud passages

Stereo Width​

Range: 0 (mono) to 2 (ultra-wide)

Effects:

  • 0: Mono-compatible
  • 1: Normal stereo
  • 1.5: Expanded soundstage
  • 2: Maximum spatial expansion

Best For Headphones: Wider settings create immersive experience

Audio Effects Master Switch​

Bypass Toggle:

  • Enable/disable all audio effects
  • Quick comparison of processed vs original
  • Useful for troubleshooting

Radio Settings​

External Media:

  • Include external/radio content
  • Degrees of separation: Limited or unlimited

Streaming Quality​

WiFi Quality:

Conversion Bitrate​

Purpose: Quality for transcoded streams

LlamaSense Smart Downloads​

Smart Downloads:

  • Algorithm: Median (default), Average, or Weighted
  • Uses historical network speed data

Prefer Downloaded Media:

  • Always: Use offline copies when available
  • Cellular: Prefer offline only on cellular
  • Never: Always stream

Settings Persistence​

Automatic Saving​

How It Works:

  • All changes saved automatically
  • 1-second debounce prevents excessive writes
  • Batched for efficiency

What's Saved:

  • All 10 settings categories
  • Server configurations
  • Custom presets (EQ, backgrounds)
  • Playback preferences

Settings Migration​

Automatic Updates:

  • Database version tracked (currently v49)
  • Automatic migration on version change
  • Preserves your preferences
  • Shows migration message during update

Migration Safety:

  • Backward compatible
  • Non-destructive
  • Logged for debugging
  • Can be forced via advanced settings

Reset Settings​

Full Reset:

  • Available in Advanced settings
  • Resets ALL settings to defaults
  • Clears custom presets
  • Persists reset to storage

Account Clear:

  • Separate from full reset
  • Clears only account data
  • Triggered on logout

Interdependent Settings​

Automatic Validation​

LlamaSense Auto-Disable:

  • If Smart Downloads enabled but quality is NOT set to Auto
  • Automatically disables Smart Downloads
  • Prevents conflicting settings

Smart Analysis Auto-Disable:

  • If Run Mode is NOT Auto but Smart Analysis enabled
  • Automatically disables Smart Analysis
  • Ensures logical consistency

Smart Workers Auto-Disable:

  • If Smart Workers enabled but thresholds are NOT Auto
  • Automatically disables Smart Workers
  • Maintains configuration integrity

Theme-Background Sync​

Automatic Behaviour:

  • Changing theme updates background
  • Matches preset for that theme
  • Enables custom backgrounds flag
  • Seamless visual transition

Debug Overlay Exclusivity​

Mutual Exclusion:

  • Only one debug overlay at a time
  • Enabling one disables others
  • Prevents performance interference
  • Clear visual feedback

Best Practices​

Recommended Settings​

For Most Users:

  • Theme: Dark (or match system)
  • Quality: Auto (let LlamaSense decide)
  • Downloads: Auto quality, WiFi preferred
  • Caching: Enabled, Next track or 10-20 tracks
  • Audio Effects: Enabled
  • Autoplay: On for continuous listening

For Audiophiles:

  • Quality: Maximum
  • EQ: Custom tuned to your headphones/speakers
  • Loudness Leveling: Enabled (-14 LUFS)
  • Limiter: Enabled for high-volume listening
  • Stream Pool: Balanced or Aggressive

For Mobile/Cellular:

  • Quality: Auto or 128-192 kbps
  • Downloads: Block cellular or limit to 128 kbps
  • Caching: Next track only or 5-10 tracks
  • Smart Workers: Enabled (prevents UI freeze)

For Offline Use:

  • Downloads: Maximum quality on WiFi
  • Lyrics: Enabled
  • Sonic Analysis: Always or Post-Container
  • Prefer Downloaded Media: Always
