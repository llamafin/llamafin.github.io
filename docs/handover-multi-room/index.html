Documentation Handover: Multi-Room → Remote Device Control

Priority: High — Critical terminology correction Date: 2026-04-08 Requested By: Engineering Team Reason: Feature mislabeled in documentation; creates false user expectations

Summary of Issue​

The feature currently documented as "Multi-Room Playback" (Section 12) is not multi-room playback in the traditional sense (synchronized audio across multiple speakers, like Sonos). Instead, it is a Remote Device Control system that allows one device to control playback on another device.

What the code actually does:

  • Device A can remotely control playback on Device B (play, pause, skip, queue management)
  • Device A's UI shows what's playing on Device B
  • Devices do NOT play audio in synchronization — only one device plays at a time

What "Multi-Room" implies to users:

  • Multiple speakers playing the same audio simultaneously (like Sonos, AirPlay 2, Chromecast Audio groups)
  • Synchronized clock timing across devices
  • Grouped zones that play in perfect sync

This is a fundamental misrepresentation. Users expecting Sonos-like multi-room functionality will be disappointed and confused.

Required Changes​

1. Rename Section 12​

Current: 12-multi-room/ Proposed: 12-remote-control/ or 12-device-control/

Rationale: The feature enables remote control of other devices, not synchronized multi-room playback.

2. Update Section Title and Subtitle​

Current:

Multi-Room Playback lets you control music playback on other devices...

Proposed:

Remote Device Control lets you control music playback on other devices from your current device...

6. Technical Specification Updates​

Current: "Multi-Room Playback in Llamafin consists of..."

Proposed: "Remote Device Control in Llamafin consists of..."

Add Clarification Box:

> **💡 What This Feature Does NOT Do**
>
> This feature does **not** provide synchronized multi-room audio playback like Sonos, AirPlay 2, or Chromecast Audio groups. It does not:
>
> - Synchronize audio timing across multiple devices
> - Create playback groups where multiple speakers play simultaneously
> - Handle clock synchronization between devices
> - Buffer audio to maintain sync across rooms
>
> **What it does do:**
>
> - Lets you remotely control playback on another device
> - Shows you what's playing on that device in real-time
> - Allows you to manage queues, skip tracks, adjust volume on the remote device
> - Only the remote device plays audio — your controller device does not play along with it

7. Integration with Player Section​

Current: "Playback Target Selection"

Proposed Addition:

When you select a remote device as your playback target, all playback commands (play, pause, skip, etc.) are sent to that device. Your local device stops playing audio (if it was playing), and the remote device starts playing instead. This is not a grouped playback mode where both devices play together.

Proposed Addition:

Expected Behavior Clarification:

  • Your controller device does not play audio simultaneously
  • This is intentional — Llamafin does not support synchronized multi-room playback

10. Feature Comparison with Plexamp/Sonos​

Add New Section (if appropriate for audience):

## How Does This Compare to Sonos or Plexamp?

Llamafin's Remote Device Control is similar in concept to how Plexamp handles remote playback — it can control playback on other devices, but it does not synchronize audio across multiple speakers like Sonos does.

**Sonos**: True multi-room synchronized audio (multiple speakers play in perfect sync)
**Plexamp**: Remote device control (control playback on other devices, one at a time)
**Llamafin**: Remote device control (same as Plexamp — control other devices, not sync them)

If you need synchronized multi-room audio, you would need a dedicated multi-room audio system (Sonos, AirPlay 2, Chromecast Audio, etc.) and use Llamafin as a remote controller for those systems.

Impact Assessment​

User Confusion Risk: HIGH​

Users seeing "Multi-Room Playback" will expect:

  • Synchronized audio across multiple speakers ❌
  • Grouped playback zones ❌
  • Sonos-like functionality ❌

When they discover it's actually remote control (one device at a time), they will feel misled.

SEO/Marketing Impact: MEDIUM​

"Multi-room playback" is a specific feature that audiophiles and smart-home users search for. Using this term incorrectly could:

  • Attract wrong audience
  • Increase bounce rate when users realize the feature doesn't match expectations
  • Damage trust in product documentation

Engineering Alignment: CRITICAL​

The engineering team has confirmed: The app does NOT implement synchronized multi-room playback. The documentation must reflect this accurately to avoid:

  • Support tickets from confused users
  • Feature requests for "actual" multi-room sync
  • Misalignment between product and documentation
