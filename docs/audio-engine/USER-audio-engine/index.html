Professional Audio Engine

Audience: End users and technical evaluators Last Updated: 2026-04-04 Version: 2.0.0

Overview​

Llamafin's audio engine is a professional-grade playback system built on the Web Audio API. It delivers studio-quality audio processing with features typically found only in dedicated desktop audio players, all within a cross-platform application.

Audio Processing Pipeline​

Signal Chain Architecture​

Every audio track passes through a sophisticated processing chain:

Audio Source → Preamp → 10-Band EQ → Stereo Width → Balance → Volume → Limiter → Analyser → Output

What This Means: Each stage applies specific audio transformations to deliver the best possible sound quality while giving you complete control over the audio characteristics.

Custom Equalizer​

Create and save your own sound signature:

  • Each band adjustable from -12 dB to +12 dB
  • Fine control over frequency response
  • Save custom profiles for different headphones or speakers

Bass & Treble Controls​

Simplified tone controls for quick adjustments:

Bass Control:

  • Adjusts the three lowest frequency bands (60Hz, 170Hz, 310Hz)
  • Applies graduated slope: deepest bass gets full adjustment, higher bass bands get partial
  • Range: -12 dB to +12 dB

Treble Control:

  • Adjusts the four highest frequency bands (6000Hz, 12000Hz, 14000Hz, 16000Hz)
  • Graduated application: highest frequencies get full adjustment
  • Range: -12 dB to +12 dB

Stereo Imaging​

Stereo Panning (Balance)​

Control the left-right balance of audio:

  • Range: -1 (full left) to +1 (full right), 0 is centre
  • Use Cases:
    • Compensate for off-centre listening position
    • Adjust for hearing impairment in one ear
    • Correct imbalanced speaker systems

Stereo Width (Haas Effect)​

Advanced spatial audio processing using the Haas effect:

How It Works:

  • One channel is delayed by up to 15 milliseconds relative to the other
  • Creates perception of wider or narrower soundstage
  • Does not affect frequency response

Width Settings:

SettingValueEffect
Narrow0Mono-compatible, centered sound
Normal1Original stereo image
Wide1.5Expanded soundstage
Ultra Wide2Maximum spatial expansion

Best Uses:

  • Headphones: Wider settings create more immersive experience
  • Speakers: Normal setting for proper stereo imaging
  • Mono systems: Narrow setting ensures compatibility

Loudness normalisation​

ReplayGain Support​

Automatic volume leveling across your entire library:

The Problem:

  • Different albums have different mastering levels
  • You constantly adjust volume between tracks
  • Modern "loudness war" recordings are much louder than older recordings

The Solution:

  • Llamafin analyses integrated loudness of each track
  • Automatically adjusts playback volume to match a standard level
  • Standard target: -14 LUFS (Loudness Units Full Scale)

How It Works:

  1. Track's loudness measured from sonic analysis data
  2. normalisation gain calculated to reach -14 LUFS target
  3. User preamp gain added (if configured)
  4. Total gain applied to playback chain

Example:

  • Track A mastered at -8 LUFS (loud): Reduced by 6 dB
  • Track B mastered at -18 LUFS (quiet): Increased by 4 dB
  • Result: Both tracks play at same perceived loudness

User Preamp​

Fine-tune the overall output level:

  • Adjusts gain before it reaches the equalizer
  • Range: -12 dB to +12 dB
  • Combined with loudness normalisation for perfect levels
  • Prevents clipping when using EQ boost

Audio Limiter​

Distortion Prevention​

High-ratio limiter prevents distortion at high volumes:

Configuration:

  • Ratio: 12:1 (enabled) or 1:1 (disabled)
  • Threshold: -10 dB
  • Knee: 10 dB (soft knee for transparent limiting)
  • Attack: 0 ms (instant response)
  • Release: 0.25 seconds

When to Use:

  • High-volume listening: Prevents peaks from distorting
  • Heavy EQ boost: Compensates for increased signal levels
  • Dynamic music: Handles sudden loud passages gracefully

Transparent Limiting:

  • Soft knee characteristic means gradual onset of limiting
  • Fast attack catches transients before they clip
  • Short release returns to normal quickly
  • You hear the music, not the limiter working

Gapless Playback​

Seamless Track Transitions​

No gaps between consecutive tracks - essential for:

  • Live albums: Continuous concert experience
  • Classical music: Multi-movement works flow naturally
  • Concept albums: Albums designed as continuous listening
  • DJ mixes: Continuous mixes without interruption

How It Works​

Three-Track Pool System:

  1. Current Track: What you're listening to now
  2. Next Track: Pre-loaded and ready for instant playback
  3. Previous Track: Cached for instant skip back

Benefits:

  • Instant track changes (no loading delay)
  • Crossfade capability (smooth transitions)
  • Previous/next always available

Smart Stream Pool​

Llamafin maintains multiple audio streams for optimal performance:

Pool Size: 6 concurrent streams (configurable 4-10)

Stream Roles:

  • Current: Actively playing
  • Next: Preloaded and ready
  • Previous: Cached for instant return
  • Spare: Available for allocation
  • Preview: Isolated 30-second previews

Crossfade (Sweet Fades)​

Smooth Track Transitions​

Automatically blend between tracks for a polished listening experience:

How It Works:

  1. As current track nears end, preloaded next track is ready
  2. Outgoing track fades out while incoming track fades in
  3. Linear fade curves for natural sound
  4. Configurable fade duration

Benefits:

  • Professional DJ-style transitions
  • Eliminates abrupt track changes
  • Creates continuous listening flow
  • Perfect for parties or background music

Smart Behaviour:

  • Won't crossfade on last track of queue
  • Respects track boundaries
  • Automatically manages stream pool for instant transitions

Audio Context Management​

Browser Autoplay Policy​

Modern browsers block audio until user interaction:

How Llamafin Handles This:

  1. AudioContext created in suspended state
  2. First user gesture (click/tap) activates audio
  3. Pending playback requests automatically retry
  4. Clear messaging if interaction needed

Seamless Experience:

  • You never see autoplay errors
  • Audio starts immediately after first interaction
  • Background tabs may require re-activation

Background Playback​

WebView Protection​

Keep audio playing even when app is in background:

Silent Audio Technique:

  • Inaudible silent audio stream keeps OS audio pipeline active
  • Prevents system from suspending playback
  • Volume: 0.0001 (completely inaudible)
  • Continuous loop of 10-second silence file

Smart Activation:

  • Active playback always protects WebView
  • Car mode always enables protection
  • Paused state has grace period
  • User configurable in advanced settings

Continue Listening Notifications​

Smart reminders to come back to your music:

How It Works:

  1. When you pause playback, notification scheduled
  2. 24-hour delay before notification appears
  3. Includes track artwork and title
  4. Deep link returns you to current track
  5. Cancelled automatically when you resume

Benefits:

  • Re-engage with your music library
  • Remind you what you were listening to
  • Easy return to your listening session

Performance Optimizations​

Zero-Allocation Frequency Data​

Visualisation data extraction optimised for performance:

Technique:

  • Single buffer allocated once
  • Same reference returned every frame
  • No garbage collection pressure
  • 60 FPS sustainable

RequestAnimationFrame Progress Tracking​

High-resolution time updates:

  • Per-stream RAF loop (not setInterval)
  • Synchronised with display refresh rate
  • Smooth, jitter-free progress updates
  • Only runs when audio context is active

Stream Pool Management​

Dynamic pool resizing:

  • Default 6 streams for optimal performance
  • Configurable from 4 to 10 streams
  • Changes applied without interrupting playback
  • Success notification when pool resized

Error Handling​

Robust Playback​

Multiple layers of protection:

Stale Event Protection:

  • Validates track ID before applying updates
  • Prevents old events from corrupting current state
  • Essential for gapless playback reliability

Crossfade Guards:

  • Ignores pause events during crossfade
  • Prevents interrupted transitions
  • Ensures smooth track changes

Self-Healing:

  • Detects stale local track data
  • Automatically recovers and retries
  • Logs warnings for debugging
  • User notified of recovery

Stream Allocation:

  • Graceful fallback when pool exhausted
  • Logs critical "pool exhausted" warnings
  • Continues playback with available resources
  • Adjustable pool size prevents exhaustion
