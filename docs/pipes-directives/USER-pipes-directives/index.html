Overview​

Pipes and directives are Angular's building blocks for transforming data and adding interactive behaviors to HTML elements. Llamafin includes 8 data formatting pipes and 6 interactive directives that work behind the scenes to present your data cleanly and add rich interactions throughout the app.

What Are Pipes?​

Pipes transform data for display. They take an input value, process it, and return a formatted output. Think of them as small utility functions that run automatically whenever the data they're applied to changes.

Example: A raw file size value of 1572864 bytes becomes "1.5 MiB" when passed through the bytes pipe.

What Are Directives?​

Directives add behaviors or animations to HTML elements. They listen for events, manipulate the DOM, or animate values over time.

Example: The long-press directive distinguishes between a quick tap (play a song) and a long press (open the context menu).

Data Formatting Pipes​

Bytes Pipe (bytes)​

What It Does: Converts raw byte counts into human-readable file sizes using binary units.

InputOutput
00 Bytes
10241 KiB
15728641.5 MiB
10737418241 GiB
10995116277761 TiB

Where You See It:

  • Download sizes and disk space usage on the Downloads page
  • Cache sizes in Settings → Advanced → Caching
  • Debug overlays showing memory and disk usage

Units: Bytes, KiB, MiB, GiB, TiB, PiB, EiB, ZiB, YiB (binary base-1024 units)

Ticks To Time String Pipe (ticksToTimeString)​

What It Does: Converts Jellyfin's internal time format ("ticks" — 100-nanosecond units) into compact, human-readable time durations.

Input (Ticks)OutputMeaning
00sZero duration
45000000045s45 seconds
180000000030m30 minutes
184500000030m 45s30 minutes, 45 seconds
936000000001d 2h1 day, 2 hours

Where You See It:

  • Track durations next to every song in your library (most common usage — 20 instances across the app)
  • Total runtime on album, artist, and playlist detail pages
  • Download statistics showing total listening time

Format: Shows only the two largest units (e.g., "1d 2h" instead of "1d 2h 30m 45s") for compactness. Unit labels are translated into your selected language.

Truncate Pipe (truncate)​

What It Does: Shortens long text to a specified character limit and appends "..." if truncated.

InputLimitOutput
"Very Long Song Title Here"15"Very Long Song..."
"John Doe"12"John Doe" (no truncation needed)

Where You See It:

  • User names in login and switch-user modals (truncated to 12 characters)
  • Movie/album descriptions on the home page (truncated to 160 characters)
  • Playlist names in the "Add to Playlist" dialogue (truncated to 20 characters)
  • Audio output names in playback settings (truncated to 15 characters)

Image URL Pipe (imageUrl)​

What It Does: Resolves album artwork and images with a comprehensive fallback chain that works both online and offline.

Resolution Chain:

  1. Local File: If the item is downloaded, loads from the local file system
  2. Remote Server: If online, builds the Jellyfin image URL with your quality settings
  3. Fallback SVG: If no image is available, generates an SVG placeholder with the item's initials

Where You See It:

  • Album artwork on all library detail pages (album, artist, genre, playlist)
  • Download page headers
  • Sonic Twins and Sonic Hero pages

Smart Features:

  • Works offline by loading cached local files
  • Adapts image quality based on your appearance settings
  • Handles platform differences (iOS/Android vs web/desktop)

Short Number Pipe (shortNumber)​

What It Does: Formats large numbers using bit-rate suffixes for compact display.

InputOutput
15001.5Kbit
15000001.5Mbit
15000000001.5Gbit

Where You See It:

  • Audio bitrate display in the full player's playback controls

Note: Despite the generic name, this pipe is specialized for bit-rate display (using base-10 units), not general number abbreviation.

Safe HTML Pipe (safeHtml)​

What It Does: Safely renders HTML content that would otherwise be escaped by Angular's built-in security sanitization.

Where You See It:

  • Song names in the Sonic Twins page (where names may contain HTML formatting)

Security: Uses Angular's DomSanitizer to mark content as trusted, ensuring only intentional HTML is rendered.

Local Media Blob Pipe (localMediaBlob)​

What It Does: Fetches local media assets (like preview images) as binary blobs and converts them to displayable URLs.

Where You See It:

  • Visualizer preview thumbnails in the "Select Visualizer" modal
  • Spinner animation previews in the "Select Spinner" modal

How It Works: Downloads the asset once, caches it in memory, and reuses the cached version for subsequent requests — preventing duplicate network calls.

Number To Array Pipe (numberToArray)​

What It Does: Converts a number into an array of sequential indices [0, 1, 2, ..., n-1]. This is a technical helper used internally by the custom swiper carousel component.

Where You See It:

  • Swiper pagination dots generation (internal component)

User Impact: You don't see this pipe directly, but it powers the pagination dots you see when swiping through carousel slides.

Interactive Directives​

Custom Scrollbar Directive (appCustomScrollbar)​

What It Does: Replaces the browser's default scrollbar with a custom-styled scrollbar that matches the app's theme.

Features:

  • Dynamic Colour: Automatically uses the dominant colour extracted from the current album artwork
  • Auto-Hide: Shows when you start scrolling, fades out after 1 second of inactivity
  • Gap Removal: Eliminates the padding gap that Ionic normally adds on the right side of scrollable content

Where You See It: On virtually every scrollable page in the app (111+ instances) — library pages, settings, modals, and player pages.

How It Works: The directive injects custom CSS into Ionic's shadow DOM and listens for scroll events to show/hide the scrollbar dynamically. When your accent colour setting changes, the scrollbar colour updates in real-time.

Animated Number Directive (animatedNumber)​

What It Does: Smoothly animates numeric transitions from the current displayed value to a new target value using a quadratic ease-out curve (fast start, slow end).

Where You See It:

  • Downloads Page: Animates total tracks, disk space, and runtime statistics when the page loads
  • Page Headers: Animates the item range display (e.g., "1–25 of 150") when pagination changes
  • Audio Items: Animates download progress indicators
  • Scheduler Page: Animates job progress percentages

Animation Details:

  • Default duration: 1 second (1000ms)
  • Easing: Quadratic ease-out (x * (2 - x)) — starts fast, slows down as it approaches the target
  • Frame rate: 60fps (uses requestAnimationFrame)
  • Stateful: Remembers the last displayed value, so if a number changes mid-animation, it smoothly transitions from the current position rather than jumping

Long Press Directive (long-press)​

What It Does: Distinguishes between a quick tap and a long press on touch devices.

Behaviour:

  • Quick Tap (release within 300ms, finger moved < 15px): Emits a "tap" event
  • Long Press (hold for 300ms without moving finger more than 15px): Emits a "press" event
  • Drag (move finger more than 15px): No event emitted (prevents accidental triggers)

Where You See It: On every media item (song, album, artist, playlist) in your library views:

  • Tap: Plays the item
  • Long Press: Opens the context menu with 25+ actions (play, shuffle, add to queue, download, share, etc.)

How It Works: Uses Ionic's GestureController for accurate touch tracking, including position monitoring to distinguish between a deliberate hold and an accidental drag.

Right Click Directive (rightClick)​

What It Does: Captures right-click (context menu) events on desktop and prevents the browser's default context menu from appearing.

Where You See It: On every media item in library views (co-located with the long-press directive) — provides desktop parity to the long-press gesture on mobile.

Behaviour:

  • Right-click on a song/album/artist → Opens the same context menu as long-press on mobile
  • Prevents the browser's default right-click menu from appearing

Count Up Directive (countUp)​

What It Does: Animates counting from 0 to a target number using a quadratic ease-out curve.

Status: Currently unused in the app. Declared and available for future use.

How It Would Work: If applied to an element, it would count up from 0 to the target value over 2 seconds (default), updating the element's text content.

Difference from animatedNumber: countUp always starts from 0 and directly sets the element's text content. animatedNumber is stateful (remembers the last value) and emits intermediate values for other components to use.

Swiper Gesture Directive (appSwiperGesture)​

What It Does: Provides touch and mouse drag gesture recognition for the custom swiper carousel component.

Features:

  • Touch Support: Works with finger gestures on mobile devices
  • Mouse Support: Works with click-and-drag on desktop
  • Swipe Detection: Recognises left and right swipes based on velocity (> 0.2 pixels/ms) and distance (> 30 pixels)
  • Scroll Prevention: Prevents page scrolling during horizontal swipes
  • Performance: Runs outside Angular's change detection zone to avoid unnecessary re-renders

Where You See It: Internally within the custom swiper carousel component (used for the full player's 3-page swipe carousel: Cover → Visualiser → Lyrics)

Outputs: Emits gestureStart, gestureMove, gestureEnd, swipeLeft, and swipeRight events that the swiper container responds to.

How They Work​

Pipe Execution Flow​

Raw Data (from API or store)
  │
  ▼
Pipe Transform Function
  │
  ├── bytes:         1572864 → "1.5 MiB"
  ├── ticksToTime:   1845000000 → "30m 45s"
  ├── truncate:      "Very Long Text" → "Very Lon..."
  └── imageUrl:      Album DTO → "https://server/Items/123/Images/Primary"
  │
  ▼
Template Rendering (displayed to user)

Directive Execution Flow​

User Interaction (touch, mouse, scroll)
  │
  ▼
Directive Event Listener
  │
  ├── long-press:   Distinguishes tap vs hold
  ├── rightClick:   Captures right-click, prevents default
  ├── animatedNumber: Animates value change over time
  └── customScrollbar: Shows/hides scrollbar on scroll activity
  │
  ▼
Event Emission (Output)
  │
  ▼
Component Reaction (open menu, update display, etc.)
