# Llamafin Screenshots Guide

This directory contains device mockups and screenshots used throughout the documentation and landing page.

## Current Screenshots

| File                         | Description                                                       |
| ---------------------------- | ----------------------------------------------------------------- |
| `home-screen.png`            | Home page with recently played, recently added, frequently played |
| `login-screen.png`           | Server login screen                                               |
| `language-selection.png`     | Language selection screen                                         |
| `settings-page.png`          | Settings page                                                     |
| `audio-eq.png`               | 10-band graphic equalizer with frequency analyzer                 |
| `audio-core-adjustments.png` | Audio core adjustments (bass, treble, etc.)                       |
| `player-record.png`          | Player in Record mode (vinyl visual)                              |
| `player-smoke.png`           | Player in Smoke visual mode                                       |
| `player-turntable.png`       | Player in Turntable mode                                          |
| `player-visualizer.png`      | Player with Butterchurn/MilkDrop visualizer                       |
| `sonic-analysis.png`         | Sonic analysis with spectral + waveform view                      |

## Specifications

- **Dimensions**: ~688x1520px (portrait phone mockups)
- **Format**: PNG with transparent backgrounds
- **Style**: Dark theme, real music data, device-framed

## Usage

In markdown:

```markdown
![10-Band Equalizer](/img/screenshots/audio-eq.png)
```

In React/JSX:

```jsx
<img src="/img/screenshots/audio-eq.png" alt="10-Band Equalizer" />
```
